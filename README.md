# API-SQLITE-TESTS - API Test Suite

Automation suite for the [JSONPlaceholder](https://jsonplaceholder.typicode.com/posts) API using **Python, pytest and requests (API)**

Built as part of my self-training for **Junior QA Automation Engineer** roles while transitioning from running a small business.


## About This Project

The tests check the status code, the number of posts, and that each post has the expected fields.

## How To Run

```
uv run pytest -v
```

## In Progress

Project is still in progress. More tests, including SQLite checks are planned.
